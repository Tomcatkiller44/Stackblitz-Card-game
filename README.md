# Card-game

[🎮 Jetzt spielen](https://tomcatkiller44.github.io/stackblitz-card-game/)

[![Open in Bolt](https://bolt.new/static/open-in-bolt.svg)](https://bolt.new/~/sb1-prcmlsr3)

Lokaler Start:

```bash
npm install
npm run dev
```

Beim ersten Mal unter [Settings → Pages](https://github.com/Tomcatkiller44/stackblitz-card-game/settings/pages)
als Quelle **GitHub Actions** auswählen. Danach wird die GitHub-Pages-Version bei jedem Push auf `main`
automatisch aktualisiert.
